The pipeline

  1. Parser Turns raw log lines into structured events. {{parser_count}} available
  2. Detector Emits an alert when an event looks anomalous. {{detector_count}} available
  3. Alert aggregation Combines alerts from several detectors. {{aggregator_count}} available
  4. Your sink A SIEM, a file, or the DetectMate Service.
audit.log

  • Streaming, not only batch

    Components consume events as they arrive, so the same pipeline runs online for real-time detection and offline over archived logs.

  • Rules to deep learning, one interface

    Cheap statistical checks and DeepLog or LogBERT share the same API — run them side by side and aggregate what they find.

  • Per event, windowed or batched

    A detector can look at each event, a sliding window, or fixed-size batches, set by its buffer mode.

  • Your own component in very little code

    mate create scaffolds a parser, detector or alert aggregator workspace with a template, tests and example data.
